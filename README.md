\# Calculadora em Python



\## Como executar o arquivo



\### Pré-requisitos

\- Ter o Python instalado no computador



\### Executando no terminal



1\. Abra o terminal na pasta onde está o arquivo

2\. Digite o comando abaixo e pressione Enter:



python calculadora.sh



3\. Digite o primeiro número e pressione Enter

4\. Digite o segundo número e pressione Enter

5\. Digite a operação desejada: +, -, \* ou /

6\. O resultado será exibido na tela
